##  Overview
This project is a **Python-based Intrusion Detection and Prevention System (IDPS)** designed to monitor system/network activity, detect suspicious behavior, and block potential malicious IPs.

It demonstrates basic cybersecurity concepts such as anomaly detection, logging, and automated response mechanisms.

---

##  Features
- IP activity monitoring  
- Attack pattern detection  
- Threshold-based anomaly detection  
- Automated IP blocking system  
- Logging of suspicious activities  
- Simple dashboard for visualization  

---

##  Project Modules

- **main.py** → Entry point of the system  
- **detector.py** → Detects suspicious behavior and attack patterns  
- **blocker.py** → Blocks malicious IPs  
- **logger.py** → Logs system activity and attacks  
- **config.py** → Stores thresholds and configuration values  
- **dashboard.py** → Displays system activity  
- **logs.txt** → Stores runtime logs  

---

##  Detection Techniques Used
- Time-window based monitoring  
- Threshold-based request analysis  
- IP behavior tracking  
- Pattern-based anomaly detection  
- Port and activity monitoring
